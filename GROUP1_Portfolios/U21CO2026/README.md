# Khadija Khalid — Portfolio

A 5-page portfolio site (Home, About, Resume, Gallery, Contact)

## Files

```
index.html       Home page
about.html        About page (bio, stats, languages)
resume.html       Education, experience timeline, projects, skills, certificates
gallery.html      Competition/event photo gallery + work videos
contact.html      Contact page
styles.css        Shared design system (colors, type, nav, footer, home)
side.css          About-page-only styles
resume.css        Resume-page-only styles
gallery.css       Gallery-page-only styles
contact.css       Contact-page-only styles
script.js         Theme toggle, mobile nav, typing effect, particles,
                   certificates, gallery, and video rendering
certificates/     certificate images & PDFs go here
gallery/          competition/event photos go here
media/            videos go here (About page clip + Gallery videos)
```


## Notes

- Theme toggle (top-right) switches between the dark espresso theme and a
  light parchment theme; the choice is remembered on return visits.
- On the Resume page, the "Print / Save as PDF" button gives visitors a
  clean, print-ready version of your resume.
- Mobile nav collapses into a hamburger menu below 720px width.
- Clicking a gallery photo opens it full-size in a lightbox; clicking a
  certificate card opens the image/PDF/verification link in a new tab.
