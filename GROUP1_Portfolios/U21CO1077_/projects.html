Final-Year Capstone Project

Smart Air Quality Monitoring System

Role: Final-Year Project Team Member contributed to development, hardware prototyping, sensor calibration, cloud telemetry, testing, and technical documentation.

An end-to-end IoT environmental monitoring station engineered to collect real-time readings of hazardous atmospheric pollutants, stream telemetry wirelessly via Wi-Fi, persist historical logs to cloud platforms, and deliver threshold-based alerts to mobile users.

Problem It Addresses

Poor ambient and indoor air quality poses severe health hazards. Conventional monitoring stations are prohibitively expensive and localized data is rarely accessible to vulnerable individuals. This project delivers an accessible, low-cost telemetry solution.

Purpose & Objective

To architect a robust IoT system utilizing an ESP32 microcontroller and multiple environmental gas sensors that autonomously measures pollutant indices, synchronizes with ThingSpeak and Firebase cloud databases, and triggers instant alerts when danger thresholds are exceeded.

Technologies & Components

ESP32 Microcontroller Arduino IDE / Embedded C++ MQ135 (Air Quality / Multi-Gas) MQ9 (Carbon Monoxide) MQ4 (Methane Sensing) Particulate Matter (PM) Sensors ThingSpeak IoT Cloud Firebase Realtime DB Mobile Application Wi-Fi Telemetry

Key System Features

Real-time Multi-gas Sampling Autonomous Sensor Calibration Wi-Fi Telemetry Pipelines Historical Time-series Charting Interactive Mobile Telemetry Threshold Warning Triggers

Smart Air Quality Monitoring Architecture

Detailed system dataflow from edge gas sensors through the ESP32 microcontroller to cloud persistence and mobile telemetry.

1. Hardware & Acquisition Layer

• MQ135: Calibrated for general air pollution indices including Ammonia (NH3), NOx, alcohol, benzene, and smoke.
• MQ9: High-sensitivity detection for Carbon Monoxide (CO) and combustible hydrocarbon gases.
• MQ4: High-selectivity sensing for Methane (CH4) and Compressed Natural Gas (CNG).
• Particulate Matter (PM): Optical detection of PM2.5 and PM10 airborne respirable particulates.

2. Microcontroller & Firmware Layer

• ESP32 32-bit Dual-Core MCU: Handles multi-channel analog-to-digital (ADC) conversions, digital filtering, and sensor pre-heating algorithms.
• Wi-Fi Telemetry: Transmits structured JSON payload via HTTP/REST and MQTT protocols at deterministic intervals.

3. Cloud Persistence & Visualization Layer

• ThingSpeak IoT: Continuous time-series charting and historical data logging with MATLAB-powered analytics.
• Firebase Realtime Database: Sub-second sync for real-time mobile push notifications and emergency alerts.
